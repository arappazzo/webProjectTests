##THIS PROJECT ONLY CONTAINS THE MAIN FILES BECAUSE UPLOADING ALL THE DEPENDENCIES WOULD TAKE A HUGE AMOUNT OF TIME AND SPACE##

## TO RE-CREATE THE PROJECT DO THE FOLLOWING (REPLACE my-project WITH THE NAME YOU WISH)##

```npm create svelte@6 my-project```

## CHOOSE SVELTE SKELETON AS OPTION. DO NOT PICK TYPESCRIPT SYNTAX
## AT THE END OF THE OPERATION, GET INTO THE CREATED FOLDER, OPEN IT IN VSCODE (VIA code .)

## ONCE INSIDE VSCODE, COPY THE CONTENT OF THE src FOLDER INSIDE THE routes FOLDER
## THEN OPEN A VSCODE TERMINAL AND RUN

```npm install```

## THIS WILL FINALISE THE DEPENDENCIES
## FINALLY RUN THE FOLLOWING TO SEE THE RESULT

```npm run dev```
